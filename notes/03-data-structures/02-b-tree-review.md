# B 树基础回扣

> 2026-10-04 · 来源：2022 下上午 m 阶 B 树判断题

## 本次错因

误选“节点中的关键字有序排列”。实际混淆了两种“有序”：

- **B 树节点内部**的关键字必须有序，这是多路查找的基础。
- **B+ 树叶子节点**通过指针连接为有序链表；普通 B 树不要求叶子成链。

## 三个基础概念

- **节点**：容器；一个节点可以存放多个关键字和多条子树指针。
- **关键字**：用于比较、查找和划分取值范围的值。
- **子树**：从内部节点的一条向下指针出发所连接的节点及其全部后代。

内部节点若有 `k` 个关键字，就有 `k+1` 棵子树。例如：

```text
               [30 | 70]
              /    |     \
           <30   30～70   >70
```

两个关键字把取值空间切成三段，因此对应三棵子树。

## m 阶 B 树必记

```text
最多 m 棵子树
最多 m-1 个关键字
节点内关键字有序
所有叶子节点在同一层
```

常见定义下，除根外的非叶子节点至少有 `ceil(m/2)` 棵子树；非空且不是叶子的根至少有两棵子树。

## B 树与 B+ 树

| B 树 | B+ 树 |
|---|---|
| 内部节点和叶子都可能保存记录 | 内部节点主要作为索引，记录集中在叶子 |
| 查找可能在内部节点结束 | 查找最终到达叶子 |
| 不要求叶子相连 | 叶子按关键字顺序连接成链 |

## 本题结论

- 根节点最多有 `m` 棵子树：正确。
- 所有叶子节点在同一层：正确。
- 节点中的关键字有序：正确。
- 叶子节点通过指针链接为有序表：错误，这是 B+ 树特征。

## 验收

2026-10-04 已独立答出：内部节点 `[20 | 50 | 80]` 有 4 棵子树，范围依次为 `<20`、`20～50`、`50～80`、`>80`。边界关键字已经保存在当前节点，因此子树对应严格区间。本知识点通过。
