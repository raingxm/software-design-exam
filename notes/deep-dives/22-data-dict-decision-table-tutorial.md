## 一、数据字典

### 人话

DFD 画「有哪些箭」；字典说明箭上**装着什么数据项**。

### 符号

| 符号 | 含义 | 读法 |
|------|------|------|
| `=` | 定义为 | 由…组成 |
| `+` | 与 | A 并且 B |
| `[ A \| B ]` | 或（选一） | A 或 B |
| `{ A }` | 重复 | A 可多次 |
| `( A )` | 可选 | A 可有可无 |

```text
加号拼一块；方括号竖线=二选一；花括号=可重复；圆括号=可省略
```

### 例子

```text
借书单 = 读者证号 + 书号 + (备注)
订单   = 订单号 + 客户信息 + { 订单明细 }
支付方式 = [ 现金 | 微信 | 银行卡 ]
```

### 已过关

| # | 问 | 答 |
|---|----|-----|
| 1 | `{ 课程成绩 }` | 可重复（多门课） |
| 2 | `[ 手机号 \| 邮箱 ]` 是否必须都有？ | 否，二选一 |
| 3 | 「地址可填可不填」 | `( 收货地址 )` |

## 二、判定表

### 四块

```text
条件桩 | 条件项（Y/N/-）
-------+----------------
动作桩 | 动作项（X / 空）
         ↑ 每一列 = 一条规则
```

| 名字 | 是什么 |
|------|--------|
| 条件桩 | 左侧：问哪些条件 |
| 条件项 | 右上：Y / N / − |
| 动作桩 | 左下：有哪些动作 |
| 动作项 | 右下：打 X 表示执行 |

### 迷你例：会员打折

| | R1 | R2 | R3 |
|--|----|----|-----|
| 是会员？ | Y | Y | N |
| 满 100？ | Y | N | − |
| 打 8 折 | X | | |
| 打 9 折 | | X | |
| 不打折 | | | X |

### 口令

```text
一列一条规则；上看条件，下看 X
− = 本规则不关心该条件
```

### 已过关

| # | 问 | 答 |
|---|----|-----|
| 1 | 每一列表示？ | 一条规则 |
| 2 | 非会员消费 200 | 不打折 |
| 3 | `−` 表示？ | 与本规则无关 / 任意 |
