### Python exception cluster COMPLETED (new since last handoff)

Card 42 asks which Python statement is correct. Expected answer: B, `raise` can manually raise an exception.

- `try`: contains code that may fail.
- `except`: matches/handles exceptions.
- `finally`: optional syntactically, but if present it executes on exit.
- `raise`: explicitly raises an exception.
- `except Exception` does not catch every `BaseException` subclass (for example `KeyboardInterrupt` and `SystemExit`).
- Python has `match...case`, not `switch...case`.
- Option A is poorly/ambiguously worded: a `finally` clause may be omitted when `except` exists, but if written it is not skipped merely because `except` exists. B is the unambiguous intended answer.
- Official reference used: https://docs.python.org/3/reference/compound_stmts.html#the-try-statement and https://docs.python.org/3/library/exceptions.html

### Current stopping point: Card 27 (4NF), verification questions just asked, NOT yet answered

The lecture on 4NF was just delivered; the user then said they were tired and asked to save/commit the handoff. The user has NOT yet answered these two verification questions:

1. 判断一个关系是否 4NF，要看每个非平凡多值依赖的什么属性是不是超键？(answer: the determinant X, i.e. whether X contains a candidate key / is a superkey)
2. 例子里 `选修(课程,老师,参考书)` 表为什么不属于 4NF？(answer: `课程` is not a superkey; the nontrivial MVDs `课程→→老师` and `课程→→参考书` have a determinant that is not a superkey)

Lecture content established:

- Classic example: `选修(课程, 老师, 参考书)`; one course has many teachers and many reference books, independent of each other.
- Therefore `课程 →→ 老师` (multivalued dependency) and `课程 →→ 参考书` both hold.
- The table has no functional-dependency problem and actually satisfies BCNF, but the two "combinatorial explosion" MVDs cause redundancy.
- 4NF definition: if every NON-TRIVIAL MVD `X →→ Y` has X containing a candidate key (i.e. X is a superkey), the relation is in 4NF.
- In the example `课程` is not a superkey, so it is not 4NF; it needs to be split into `(课程,老师)` and `(课程,参考书)`.
- Note the "non-trivial" qualifier: if `Y ⊆ X` (or X∪Y = all attributes), the MVD is trivial, harmless, and needs no handling.
