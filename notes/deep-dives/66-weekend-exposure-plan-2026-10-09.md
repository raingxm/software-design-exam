# 2026-10-09～10-11 · 周末集中暴露计划

## 目标

- **上午卷风险**：大量依赖记忆的知识点可能遗忘；用一套压缩限时卷暴露“见过但忘记 / 完全陌生 / 审题失误”。
- **下午卷风险**：单题停留过久导致整卷来不及；用一套连续 `150min` 正式样本验证题型切换和时间节点。
- 本轮先集中暴露问题，不在作答过程中查资料或即时订正；周日统一复盘，避免做卷与学习混在一起而失去真实数据。

## 10/9 晚 · 上午卷压缩限时诊断

### 题目与口径

- 首选：**2021 年下半年上午官方卷**；若确认已经完整做过，则换另一套未做过的官方上午卷。
- 作答 `75～85min`，核对总分约 `10min`，记录不确定项约 `5min`。
- 这是记忆与速度压力诊断，**不冒充正式 `150min` 样本**。
- 闭卷、连续、不查资料；到时立即停笔，未完成题数本身也是数据。

### 作答标记

- `△`：两个选项间摇摆，知识似乎见过；
- `?`：概念遗忘，主要靠猜；
- `×`：完全陌生。

### 当晚只记录

```text

得分：      /75
实际作答时间：
到时未完成：      题
△：      题
?：      题
×：      题
完全陌生或明显遗忘的知识簇：
```

- 底线 `45/75`，目标 `50～55/75`。
- 当晚不逐题深挖；只核对答案、计分和保存标记，保证休息。

## 10/10 下午 · 2020 下半年下午正式整卷

### 执行规则

- 连续闭卷 `150min`，不暂停、不查答案、不边做边订正。
- 五题同场完成；选做题固定 Java。
- 单个空卡住超过 `5min`：保留当前答案、做标记并继续。

### 时间节点

| 累计时间 | 应完成 |
|---|---|
| `30min` | 试题一 DFD |
| `60min` | 试题二数据库 |
| `85min` | 试题三 UML |
| `120min` | 试题四算法 |
| `140min` | Java |
| `150min` | 检查并停笔 |

算法题执行优先级：

1. 先拿策略、状态/变量含义和复杂度；
2. 再根据递推式或代码上下文填空；
3. 具体实例手算最多 `5min`，不能为最后 `3` 分拖垮 Java。

目标：底线 `>=48/75`、目标 `>=52/75`；UML `>=10/15`；DFD+数据库+UML `>=32/45`。

## 10/11 · 两卷集中复盘

### 上午卷分类

- **遗忘**：学过但不能稳定回忆；
- **陌生**：此前未建立知识框架；
- **失误**：会做但审题、计算或选项排除错误。

优先处理重复出现的知识簇，不按题号从头写长笔记。

### 下午卷分类

- 知识不会；
- 推导速度慢；
- 卡题超过 `5min` 未跳；
- 标识符、方向、边界或书写失误。

复盘后只选最高频的三个缺口进入下一周；算法专项按 **分治 → 贪心 → 第二道陌生回溯/分支限界** 补齐覆盖，动态规划转为间隔复测。

## 本轮完成标准

- 得到一份上午压缩诊断数据，包括不确定项分类；
- 得到第一份连续、闭卷、限时 `150min` 下午整卷样本；
- 能定位下午时间消耗发生在哪一道题，而不是只说“整卷时间紧”；
- 周日完成问题聚类并确定下一周前三项，不连续第三天盲目刷整卷。
