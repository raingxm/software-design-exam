#### 1. 已完成
- 订正一道 DRAM/SRAM 选择题：正确项为 **①④**
- 明确 DRAM 的特点：动态、需要刷新、结构简单、集成度高、成本低、速度较慢，常用于主存

2. S = Static = 静态 = 不刷新 = 快 = 贵 = 低集成 = Cache
3. DRAM 胜在容量/成本，SRAM 胜在速度/无需刷新

## Session: 2026-09-03（森林转二叉树遍历对应过关）
### 话题：为什么树/森林遍历能对应二叉树前序和中序

#### 1. 已完成
- 追问并理解森林转二叉树的遍历对应关系：
  - 树的先根遍历 = 转换后二叉树的前序遍历
  - 树的后根遍历 = 转换后二叉树的中序遍历
  - 森林的先序遍历 = 转换后二叉树的前序遍历
  - 森林的中序遍历 = 转换后二叉树的中序遍历
- 关键原因补上：左指针串第一个孩子，右指针串下一个兄弟；二叉树前序“根->左->右”对应普通树“先根再孩子兄弟链”
- 中序原因补上：一个结点的全部孩子及其兄弟链都在该结点左子树里，所以二叉树中序“左->根->右”对应普通树“先孩子子树再根”
- 已在 [树与二叉树高频公式表](./42-tree-binary-tree-cheatsheet.md) 补充原因解释和例子

#### 2. 新口令
1. 前序先看根，所以对应树/森林先序
2. 中序先走左子树；左子树里装的是孩子和孩子兄弟链，所以对应树的后根/森林中序
3. 遍历对应题不用重画全图，先认“左孩子右兄弟”即可

#### 3. 交给续学
- 若题目给“转换后二叉树的前序/中序”，直接映射回森林先序/中序或树先根/后根
- 下次遇到森林转换题，优先判断考的是结点数范围还是遍历对应

- 明确每个索引块可存地址项数：`floor(1024 / 3) = 341`
- 关键理解补上：二级索引块里的“指针”不是另一个未知大小的内存指针，考试里仍按题目给的“块号 3B”计算

2. 一级 = `N` 个数据块；二级 = `N` 个一级索引块 × 每个一级索引块 `N` 个数据块

### 话题：循环队列 + 哈夫曼 WPL/编码 — P0 缺口已关

#### 1. 循环队列（闭卷全对）
- 三公式：空 `front==rear`、满 `(rear+1)%m==front`、个数 `(rear-front+m)%m`
- 绕回时 rear < front 仍用公式；最多 m−1 个元素

#### 2. 哈夫曼 WPL（闭卷全对）
- n 叶子 → n−1 次合并，每轮取最小两个
- WPL：逐叶子 Σ(权×边数) 或 合并和法（如 5+9+16+26=56）

#### 3. 哈夫曼编码
- 左0右1 从根到叶读路径；边数 = 编码位数
- 前缀码：无编码是另一编码的前缀；解码从根走，到叶输出后回根

### 话题：HRRN 非抢占手算 — 已掌握

#### 1. 掌握要点
- 公式：`R = (W + S) / S`，`W = 决策时刻 − 到达时间`
- 每次作业结束才重新算当前**就绪**作业的 R，**选最大**；不要凭「短作业优先」的感觉改结果
- FCFS「短作业等长作业」：先到的长作业占 CPU，后面短作业干等 → 平均等待往往偏长

#### 2. 五作业例题（已核对）
| 作业 | 到达 | 服务 |
|------|------|------|
| A | 0 | 7 |
| B | 2 | 4 |
| C | 4 | 1 |
| D | 5 | 4 |
| E | 6 | 2 |

- **正确顺序**：A → C → B → E → D
- 时刻 8：`R_B=2.5 > R_E=2` → 必须选 **B**（初稿误选 E 已纠正）
- 时刻 12：`R_E=4 > R_D=2.75` → 再选 E，最后 D
- 平均周转 **8.4**，平均等待 **4.8**
- 逐步填表见 [OS 回顾笔记 · HRRN 五作业例](../02-os/04-os-review.md#hrrn-五作业例已掌握)
