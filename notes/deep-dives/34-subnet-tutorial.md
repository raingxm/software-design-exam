## 总口令

```text
/n 的 n = 网络位个数；剩下 32-n = 主机位
块大小 = 2^主机位（末字节里一跳多长）
网络号 = 该块的起点（主机位全 0）
广播  = 该块的终点（主机位全 1）
可用主机 = 块大小 - 2
同网 = 网络号相同
```

**操作步骤**：先算块大小 → 在末字节按块大小切分（0、64、128…）→ 看 IP 落在哪一块 → 写网络号、广播、可用范围。

---

## 零、名词（先懂再背）

| 词 | 意思 |
|----|------|
| **末字节** | IP 四段里**最后一段**，如 `192.168.1.`**`100`** 中的 100 |
| **C 类地址** | 习惯上 `192.168.1.x` 这种；默认 `/24`，前三段表网、末字节表主机 |
| **只动最后一个字节** | 从 `/24` 划成 `/26` 时，**192.168.1** 不变，只有末字节（0/64/128/192…）在变 |
| **每 N 个切成一块** | 末字节的 0～255 按**块大小**分组，每组是一个子网 |

---

## 一、一条龙：192.168.1.100/26

`/26` → 网络位 26，主机位 6。  
块大小 `2^6 = 64`。掩码 `255.255.255.192`（256-64=192）。

末字节按 64 一跳切：`0 · 64 · 128 · 192`（再到 256 越界）。

100 落在 **64～127** 这一块：

| 项 | 值 |
|----|-----|
| 网络号 | 192.168.1.**64** |
| 广播 | 192.168.1.**127** |
| 可用 | .65 ～ .126 |
| 可用台数 | 64 - 2 = **62** |

130 落在 128～191，网络号是 `.128`，和 `.100` **不同网**。

---

## 二、常考掩码（末字节）

| /n | 掩码末位 | 块大小 | 可用主机 |
|----|----------|--------|----------|
| /24 | 0 | 256 | 254 |
| /25 | 128 | 128 | 126 |
| /26 | 192 | 64 | 62 |
| /27 | 224 | 32 | 30 |
| /28 | 240 | 16 | 14 |
| /30 | 252 | 4 | 2 |

从 /24 再借 k 位 → 子网个数 `2^k`。例：/24 划成 /26，借 2 位，**4** 个子网。

A/B/C 类默认：A=/8、B=/16、C=/24。私网了解：`10/8`、`172.16/12`、`192.168/16`。

## 三、易混

| 对比 | 怎么分 |
|------|--------|
| 网络号 vs 第一个可用 | 网络号主机位全 0，**不能**分给主机；下一号才可用 |
| 广播 vs 最后一个可用 | 广播全 1，**不能**分给主机；前一号才可用 |
| 同网 | 只比网络号，不要只看「看起来都叫 192.168.1.x」 |
