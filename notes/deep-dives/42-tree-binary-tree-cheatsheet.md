# 树与二叉树高频公式表

> 适用：软考中级软件设计师上午选择题 + 下午基础概念题  
> 用法：先背公式，再配合 [数据结构总复习](../03-data-structures/01-data-structures-review.md) 和 [树还原专题](./06-tree-reconstruction-tutorial.md) 做手算

---

## 1. 树的通用公式

- 树有 `n` 个结点，则边数 = `n - 1`
- 若度为 `i` 的结点数为 `n_i`，则总结点数：

```text
n = n_0 + n_1 + n_2 + ... + n_k
```

- 一般树叶子数公式：

```text
n_0 = 1 + Σ(i - 1)n_i   (i >= 1)
```

记忆：非叶子多“分叉”出来的孩子数，最后都会变成叶子。

---

## 2. 二叉树高频性质

- 第 `i` 层最多结点数：`2^(i-1)`，`i >= 1`
- 深度为 `k` 的二叉树最多结点数：`2^k - 1`
- 深度为 `k` 的满二叉树叶子数：`2^(k-1)`
- `n` 个结点的二叉树：
  - 最小可能深度：`⌈log2(n + 1)⌉`
  - 最大可能深度：`n`

---

## 3. 二叉树结点关系公式

设：

- `n0` = 度为 0 的结点数（叶子）
- `n1` = 度为 1 的结点数
- `n2` = 度为 2 的结点数

则：

```text
n = n0 + n1 + n2
n0 = n2 + 1
```

推论：

- 已知 `n2`，立刻得叶子数 `n0 = n2 + 1`
- 二叉树总边数仍为 `n - 1`

---

## 4. 满二叉树 vs 完全二叉树

### 满二叉树

- 每一层都满
- 深度 `k` 时：

```text
总结点数 = 2^k - 1
叶子数 = 2^(k-1)
```

### 完全二叉树

- 除最后一层外都满
- 最后一层结点连续集中在左侧
- `n` 个结点的完全二叉树深度：

```text
⌊log2 n⌋ + 1
```

- `n` 个结点的完全二叉树叶子数：

```text
⌈n / 2⌉
```

反推：

- 已知叶子数 `L`，完全二叉树总结点数最多可到 `2L`

---

## 5. 顺序存储下标公式

这是最容易错的点。顺序存储按“完全二叉树位置”编号，不是按图上已有结点连续编号。

### 下标从 1 开始

若某结点下标为 `i`，则：

```text
左孩子 = 2i
右孩子 = 2i + 1
双亲 = ⌊i / 2⌋
```

### 下标从 0 开始

若某结点下标为 `i`，则：

```text
左孩子 = 2i + 1
右孩子 = 2i + 2
双亲 = ⌊(i - 1) / 2⌋
```

秒杀口令：

- 题目给 `A=1, B=2, C=3`，就用“从 1 开始”公式
- 中间空位必须保留，不能把后面的结点往前挤

---

## 6. 链式存储常考结论

- 含 `n` 个结点的二叉链表，共有 `2n` 个指针域
- 实际非空指针数为 `n - 1`
- 空指针数为：

```text
2n - (n - 1) = n + 1
```

所以常考结论：`n` 个结点的二叉链表，空链域数为 `n + 1`

---

## 7. 遍历公式与判定

### 三种基本遍历

- 前序：`根 -> 左 -> 右`
- 中序：`左 -> 根 -> 右`
- 后序：`左 -> 右 -> 根`

### 高频结论

- 二叉排序树（BST）中序遍历结果为递增序列：BST 左 < 根 < 右，中序正好按左 -> 根 -> 右访问
- 按序列构造 BST 时，第一个数是根；后续元素逐个插入，插入顺序会影响树形
- 层序遍历需要借助队列
- 深度优先遍历常和栈/递归对应

---

## 8. 由遍历序列还原二叉树

唯一确定：

- 中序 + 前序
- 中序 + 后序

不能唯一确定：

- 前序 + 后序

手算模板：

1. 前序第一个 / 后序最后一个先定根
2. 去中序中找根
3. 根左边是左子树，右边是右子树
4. 递归切分

## 9. 森林与二叉树转换

森林转二叉树采用**左孩子右兄弟**表示法：

```text
左指针 = 第一个孩子
右指针 = 下一个兄弟
```

核心结论：

- 一棵树转二叉树后，根结点一定没有右孩子，因为根没有兄弟
- 森林转二叉树后，第一棵树的根是整棵二叉树的根
- 第一棵树根的右子树，包含第 2 棵树、第 3 棵树、...、最后一棵树的全部结点

若森林由三棵树组成，结点数分别为 `n1, n2, n3`：

```text
二叉树根 = 第 1 棵树的根
根的左子树结点数 = n1 - 1
根的右子树结点数 = n2 + n3
整棵二叉树结点数 = n1 + n2 + n3
```

遍历对应关系：

```text
树的先根遍历 = 转换后二叉树的前序遍历
树的后根遍历 = 转换后二叉树的中序遍历
森林的先序遍历 = 转换后二叉树的前序遍历
森林的中序遍历 = 转换后二叉树的中序遍历
```

原因：

- 前序是“根 -> 左 -> 右”；左边是第一个孩子，右边串兄弟，所以等价于先访问根，再从左到右访问孩子子树
- 中序是“左 -> 根 -> 右”；一个结点的全部孩子和孩子兄弟链都在它的左子树里，所以等价于先访问所有孩子子树，再访问根

例：

```text
普通树：A 的孩子为 B、C、D；C 的孩子为 E、F

树先根遍历：A B C E F D
树后根遍历：B E F C D A

转换后二叉树前序：A B C E F D
转换后二叉树中序：B E F C D A
```

易错点：

- 右孩子不是“第二个孩子”，而是“下一个兄弟”
- 根的右子树不是第一棵树的一部分，而是森林中剩余树
- 树转二叉树后，原树的兄弟关系会沿右指针串起来

## 10. 题目里的高频关键词

- “叶子结点数”优先想到：`n0 = n2 + 1`
- “第 i 层最多多少结点”优先想到：`2^(i-1)`
- “深度为 k 的二叉树最多多少结点”优先想到：`2^k - 1`
- “完全二叉树深度”优先想到：`⌊log2 n⌋ + 1`
- “顺序存储下标”优先看下标起点，再套孩子/双亲公式
- “二叉链表空指针数”优先想到：`n + 1`
- “森林转二叉树右子树”优先想到：除第一棵树外的全部树

---

## 11. 考场 20 秒检查法

1. 先判断题目讨论的是一般树、二叉树、满二叉树，还是完全二叉树
2. 看到“下标”先看从 `0` 还是从 `1` 编号
3. 看到“叶子数”优先尝试 `n0 = n2 + 1`
4. 看到“遍历还原”先检查有没有中序
5. 看到“森林转二叉树”先写左孩子右兄弟
6. 如果树很偏，顺序存储下标会跳得很快，这通常说明你算对了
