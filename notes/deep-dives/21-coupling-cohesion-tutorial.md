> 第 5 / 6 章交界 · 模块化设计高频选择

## 总口令

```text
耦合 = 模块之间有多黏（越低越好）
内聚 = 模块内部有多齐心（越高越好）
目标：高内聚、低耦合
```

---

## 一、耦合（模块之间）

### 从好到差

```text
非直接 → 数据 → 标记 → 控制 → 外部 / 公共 → 内容
 最好                                              最差
```

| 类型 | 一句话 | 题干信号 |
|------|--------|----------|
| **非直接** | 不直接来往，只经上级间接协作 | 无直接调用/传参 |
| **数据** | 只传**简单值** | `int` / 金额 / 学号 |
| **标记** | 传整块**结构体**，常用其中几字段 | 传 `Student` / `Order` 对象 |
| **控制** | 传**开关**决定对方分支 | `flag`、`mode`、`0=查 1=删` |
| **外部** | 依赖同一**外部约定** | 同一文件格式 / 设备 / 协议 |
| **公共** | 共用**全局数据** | 全局数组、公共数据区 |
| **内容** | 改对方**内部**或跳进中间执行 | 改私有变量、GOTO 进内部 |

### 耦合口令

```text
简单值=数据；整包结构=标记；开关指挥=控制；
全局共用=公共；外部格式/设备=外部；伸手改内脏=内容（最差）
```

### 易混三对

| 对比 | 怎么分 |
|------|--------|
| 数据 vs 标记 | 简单标量 → 数据；整包记录只用部分 → 标记 |
| 控制 vs 内容 | 传 flag 让对方自己分支 → 控制；直接改对方内部 → 内容 |
| 外部 vs 公共 | 绑外部介质/格式 → 外部；绑程序内全局区 → 公共 |

### 已过关例题（耦合）

| # | 场景 | 答 |
|---|------|-----|
| 1 | 传 `int studentId` 查成绩 | 数据 |
| 2 | 传整个 `Student`，只用 `id`/`name` | 标记 |
| 3 | 传 `mode`：0 查 / 1 删 | 控制 |
| 4 | 都读写全局 `g_buffer[]` | 公共 |
| 5 | 必须同一套银行报文定长格式 | 外部 |
| 6 | 改对方内部变量 / 跳进中间 | 内容 |
| 7 | 好→差排序：数据→标记→控制→公共→内容 | ✅ |

## 二、内聚（模块内部）

### 从差到好

```text
偶然 → 逻辑 → 时间内 → 过程 → 通信 → 顺序 → 功能
 最差                                              最好
```

| 类型 | 一句话 | 题干信号 |
|------|--------|----------|
| **偶然** | 无关语句硬塞一起 | 杂烩、彼此无关 |
| **逻辑** | 同类操作捆一起，**参数选**干哪件 | 增删改查一模块 + 开关 |
| **时间内** | 因**同一时段**才放一起 | 启动初始化、关机清理 |
| **过程** | 按**流程图步骤**捆，数据未必相关 | 严格步骤序，主绑控制流 |
| **通信** | 操作**同一数据**，无明确接力 | 都读写同一张表 |
| **顺序** | 前步**输出** = 后步**输入** | 流水线、产物喂下一步 |
| **功能** | **只干一件事** | 单一明确功能 |

### 内聚口令

```text
碰巧塞=偶然；开关选同类=逻辑；同一时刻做=时间内；
按步骤捆=过程；同数据=通信；输出喂输入=顺序；只干一件=功能（最好）
```

### 易混三对

| 对比 | 怎么分 |
|------|--------|
| 逻辑 vs 时间内 | 类型开关选功能 → 逻辑；「启动时都要做」→ 时间内 |
| 过程 vs 顺序 | 绑流程图步骤 → 过程；绑数据接力（输出→输入）→ 顺序 |
| 通信 vs 顺序 | 同数据、不强调接力 → 通信；有产物喂下一步 → 顺序 |

### 已过关例题（内聚）

| # | 场景 | 答 |
|---|------|-----|
| 1 | 算工资 + 打菜单 + 播音乐，无关 | 偶然 |
| 2 | 去空格 → 转大写 → 查非法（输出喂输入） | 顺序 |
| 3 | 只根据订单号扣一次库存 | 功能 |
| 4 | 参数选增加/删除/修改 | 逻辑 |
| 5 | 启动：开日志/读配置/连库/清临时 | 时间内 |
| 6 | 都读写学生登记表，无接力 | 通信 |
| 7 | 严格按流程图 1→2→3 捆 | 过程 |
| 8 | 差→好：偶然→逻辑→时间内→过程→通信→顺序→功能 | ✅ |

## 三、考试要什么 / 不要什么

- **要**：给场景选耦合/内聚类型；两条排序默写正确
- **不要**：纠结外部与公共谁更差的细枝（题干信号分清即可；排序题里常一起出现在内容之前）
- 和第 6 章：变换/事务是「怎么拆模块」；耦合内聚是「拆完好不好」
