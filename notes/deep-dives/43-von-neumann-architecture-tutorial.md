# 冯诺依曼体系结构速通

> 第 1 章计算机组成 · 上午选择题高频概念  
> 关键词：存储程序、程序和数据同存主存、二进制、CPU 取指执行

---

## 一、主存是不是内存？

是。软考语境里：

```text
主存 = 主存储器 = 内存 = Main Memory
```

常见主存通常指 RAM，是 CPU 可以直接按地址访问的存储器。它和 Cache、寄存器、外存不是一回事：

| 层次 | 中文 | 作用 |
|------|------|------|
| 寄存器 | CPU 内部小容量高速部件 | 临时保存操作数、地址、状态 |
| Cache | 高速缓存 | 保存主存内容的高速副本，缓解 CPU 和主存速度差 |
| 主存 | 内存 / RAM | 存放正在运行的程序和数据 |
| 外存 | 硬盘 / U 盘 / 光盘 | 长期保存程序和数据 |

考试里看到“程序和数据存在哪里”，按冯诺依曼模型优先答：**主存**。Cache 只是加速用的副本，不是数据的固定归宿。

## 二、冯诺依曼结构四个核心点

### 1. 存储程序

程序不是靠人工拨开关一步步控制，而是先作为数据一样装入主存，然后 CPU 自动取出指令执行。

```text
程序预先存入主存 -> CPU 按指令序列自动执行
```

这是冯诺依曼体系最核心的思想。

### 2. 指令和数据都用二进制表示

计算机底层只认识 `0` 和 `1`。指令也要编码，数据也要编码。

```text
指令 = 二进制编码
数据 = 二进制编码
```

### 3. 程序和数据同等地位存放在主存

“同等地位”不是说 CPU 分不清指令和数据，而是说它们都可以作为二进制信息存放在同一个主存空间里。

```text
主存中既放指令，也放数据
```

CPU 根据当前执行流程，把某些二进制内容当作指令取出，把另一些二进制内容当作数据处理。

### 4. CPU 按地址访问并执行指令

CPU 中的 PC 保存下一条指令地址，CPU 周期性完成：

```text
取指 -> 译码 -> 执行
```

相关部件：

| 部件 | 作用 |
|------|------|
| PC | 保存下一条将要执行的指令地址 |
| IR | 保存当前正在执行的指令 |
| 控制器 | 译码并发出控制信号 |
| 运算器 / ALU | 完成算术逻辑运算 |

## 三、这道题为什么 B 错？

题干问“关于冯诺依曼计算机，不正确的是”：

```text
B. 程序指令总是存储在主存中，而数据则存储在高速缓存中
```

错因有两层：

1. 冯诺依曼结构强调**程序和数据都存放在主存**。
2. Cache 是主存的高速副本，里面可能缓存指令，也可能缓存数据，不是“数据专门存 Cache”。

更准确的说法应该是：

```text
程序和数据都存放在主存中，Cache 用来临时保存近期可能访问的主存内容。
```

## 四、易考点

### 存储程序控制

常见问法：

```text
冯诺依曼计算机的基本思想是什么？
```

优先选：

```text
存储程序
```

或：

```text
程序存入存储器，按指令自动执行
```

### 指令和数据同存

常见正确表述：

```text
指令和数据都以二进制形式存放在存储器中
指令和数据在存储器中地位相同
指令和数据可存放在同一存储器中
```

常见错误表述：

```text
指令和数据必须存放在不同存储器中
数据存 Cache，指令存主存
程序只能存外存，执行时不进入主存
```

### CPU 五大组成

经典冯诺依曼计算机由五大部件组成：

```text
运算器、控制器、存储器、输入设备、输出设备
```

其中：

```text
CPU = 运算器 + 控制器
```

不要把主存、输入输出设备算进 CPU。

### 取指执行

程序自动执行的微观过程是：

```text
PC 给出地址 -> 从主存取指令 -> 放入 IR -> 译码 -> 执行 -> 修改 PC
```

考试最爱问：

```text
PC 存下一条指令地址
IR 存当前指令
```

## 五、易错点

### 1. 把主存和 Cache 混为一谈

```text
主存 = 内存，程序和数据的主要运行存放位置
Cache = 主存内容的高速副本
```

Cache 可以缓存数据，也可以缓存指令。现代 CPU 还可能有指令 Cache 和数据 Cache，但这不改变冯诺依曼模型里“程序和数据同存主存”的考点。

### 2. 把外存当作运行位置

程序平时可以保存在硬盘里，但运行时需要装入主存，CPU 才能直接取指执行。

```text
外存保存程序
主存运行程序
CPU 直接访问主存取指
```

### 3. 把“同等地位”理解成“没有类型”

主存里都是二进制位，但 CPU 会按指令格式、数据格式解释它们。题目说“同等地位”，重点是存储形式和存储位置，不是否认指令和数据语义不同。

### 4. 和哈佛结构混淆

哈佛结构把程序存储器和数据存储器分开，指令通路和数据通路可分离。冯诺依曼结构的经典特点是程序和数据同存，分时访问。

考题里如果出现：

```text
指令和数据必须在不同存储器中物理分离
```

这不是冯诺依曼，是哈佛结构倾向。

---

## 六、速记卡

```text
冯诺依曼 = 存储程序
程序 + 数据 = 二进制，同存主存
CPU = 运算器 + 控制器
执行 = PC 取址，IR 存当前指令，控制器译码，ALU 运算
Cache 只是主存副本，不是数据专属存储器
哈佛结构才强调指令存储和数据存储分离
```
