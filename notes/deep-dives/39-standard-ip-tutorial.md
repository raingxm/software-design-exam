## 一、标准化（认代号）

### 常见标准代号

| 代号 | 含义 | 考试点 |
|------|------|--------|
| **GB** | **强制性**国家标准 | 必须执行 |
| **GB/T** | **推荐性**国家标准 | T = 推荐，最常见 |
| **GB/Z** | 国家标准化**指导性**技术文件 | 指南性质 |
| **GJB** | 国家军用标准 | 了解 |
| **ISO** | 国际标准化组织 | 国际标准 |
| **IEC** | 国际电工委员会 | 电工/电子相关 |
| **IEEE** | 电气电子工程师学会 | 如 IEEE 802 网络 |

**易混**：`/T` = 推荐性，不是「临时」；没有 `/T` 的 GB 才是强制性。

### 标准层次（了解）

```text
国标 → 行标 → 地标 → 企标
（范围从大到小；另有国家军用标准 GJB）
```

### 软考常提的文档标准（认名字即可）

| 标准 | 干什么 |
|------|--------|
| **GB/T 8567** | 软件生存周期 **文档** 编制（需求、设计、测试文档等） |
| **GB/T 11457** | 软件工程 **术语** |
| **GB/T 9385** | 计算机软件 **需求说明** 编制指南 |

**考试**：问「软件项目文档规范常参考哪个」→ 偏向 **8567**。

## 二、软件著作权（P0 · 最常考）

### 保护什么 / 不保护什么

| 保护 ✅ | 不保护 ❌ |
|---------|-----------|
| **源程序**、目标程序 | **思想**、原理 |
| **文档**（说明书、设计文档等） | 单纯的 **算法**、数学方法 |
| 表达形式 | 操作方法、处理过程本身 |

**口诀**：保护 **表达**，不保护 **思想**。

### 怎么取得

- 软件著作权 **自动产生**（开发完成即享有）
- **登记自愿**，登记证书是诉讼时的初步证明（了解）

### 归属（场景题高频）

| 场景 | 著作权归谁 |
|------|------------|
| **职务开发**（员工本职工作、单位主持、单位担责） | 一般归 **单位** |
| **委托开发** | **合同约定**；无约定 → 归 **受托方** |
| **合作开发** | **共同享有**（可合同约定份额） |
| 个人独立开发 | 开发者本人 |

**易混**：委托开发 **没写合同** → 考纲常选 **受托方**，不是委托方。

### 保护期（记大意，不必抠每条款）

| 主体 | 保护期 |
|------|--------|
| **自然人** | 终生 + 死亡后 **50 年** |
| **法人 / 其他组织** | **50 年**（截止于首次发表后第 50 年 12 月 31 日；开发完成 50 年内未发表则不再保护） |

## 三、专利、商标、商业秘密（P1 · 辨型）

| 类型 | 特点 | 与著作权对比 |
|------|------|--------------|
| **著作权** | 自动产生，保护表达 | 软件默认走这条 |
| **发明专利** | 须 **申请**，保护技术方案 | 保护「怎么做」，不是源代码文本 |
| **商标** | 区分商品/服务来源 | 软件产品名、Logo |
| **商业秘密** | 采取保密措施的不公开信息 | 不公开、无固定保护期 |

**考试**：
- 「算法本身」→ 通常用 **著作权** 保护程序表达；**单纯算法** 一般 **不授予专利**（与具体技术方案结合可申请专利，了解即可）
- 「未公开的核心配方/客户列表」→ **商业秘密**

## 四、侵权 vs 合理使用（认场景）

### 常见侵权

- 未经许可 **复制**、发行、传播他人软件
- **破解**、去除版权技术措施
- 抄袭代码/文档表达

### 合理使用（了解，少考）

- 为学习、研究 **少量复制**（非商业）
- 安装软件应遵守 **许可协议**（单机版、企业版、开源许可证各不同）

**开源许可**（了解）：GPL、Apache、MIT 等 — 考「使用开源组件是否要遵守许可证」→ **要**。

## 五、场景 → 答案（速查）

| 题干关键词 | 选什么 |
|------------|--------|
| 推荐性国家标准 | **GB/T** |
| 强制性国家标准 | **GB** |
| 保护源代码和文档 | **著作权** |
| 保护思想、算法本身 | **不**由著作权保护思想 |
| 员工在单位开发本职软件 | 著作权归 **单位** |
| 委托开发且合同未约定 | 归 **受托方** |
| 合作开发 | **共同**享有 |
| 软件文档国标 | **GB/T 8567** |
| 必须申请才取得的权利 | **专利**（著作权自动） |
