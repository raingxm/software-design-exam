## 一、标准化（认代号）

### 常见标准代号

| 代号 | 含义 | 考试点 |
|------|------|--------|
| **GB** | **强制性**国家标准 | 必须执行 |
| **GB/T** | **推荐性**国家标准 | T = 推荐，最常见 |
| **GB/Z** | 国家标准化**指导性**技术文件 | 指南性质 |
| **GJB** | 国家军用标准 | 了解 |
| **ISO** | 国际标准化组织 | 国际标准 |
| **IEC** | 国际电工委员会 | 电工/电子相关 |
| **IEEE** | 电气电子工程师学会 | 如 IEEE 802 网络 |

**易混**：`/T` = 推荐性，不是「临时」；没有 `/T` 的 GB 才是强制性。

### 标准层次（了解）

```text
国标 → 行标 → 地标 → 企标
（范围从大到小；另有国家军用标准 GJB）
```

### 软考常提的文档标准（认名字即可）

| 标准 | 干什么 |
|------|--------|
| **GB/T 8567** | 软件生存周期 **全套文档** 怎么编制（需求、设计、测试、用户手册等都算在内） |
| **GB/T 11457** | 软件工程 **术语** 表（规定标准里的用词） |
| **GB/T 9385** | 只规定 **需求说明** 这一份怎么写 |

三个号都是推荐性国家标准。考试不考条文，只看题干在问哪一类：

- 题干写「软件项目文档规范」「开发文件编制」，选 **8567**。
- 题干出现「软件工程术语」「术语字典」，选 **11457**。
- 题干点明「需求说明编制指南」或「需求规格说明」，选 **9385**。

**三种问法的口令（2026-10-18 闭卷错题钉死）**：

| 题干在问 | 选 | 一句话 |
|---|---|---|
| 术语、用词怎么定义 | 11457 | 只管「词」，不管「文档」 |
| 需求说明这一份怎么写 | 9385 | 只管「一份」 |
| 全套开发文档怎么编制 | 8567 | 管「全套」 |

错法提醒：看到「需求规格说明」不要顺手选 11457 —— 11457 不是文档标准，是术语标准。

**8567 和 9385 最容易混**：8567 是全套文档的总规范，需求说明只是其中一种；9385 专门讲需求说明这一份。题干没点明「只要需求」，选 **8567**。

## 二、软件著作权（P0 · 最常考）

### 保护什么 / 不保护什么

| 保护 ✅ | 不保护 ❌ |
|---------|-----------|
| **源程序**、目标程序 | **思想**、原理 |
| **文档**（说明书、设计文档等） | 单纯的 **算法**、数学方法 |
| 表达形式 | 操作方法、处理过程本身 |

**口诀**：保护 **表达**，不保护 **思想**。

### 怎么取得

- 软件著作权 **自动产生**（开发完成即享有）
- **登记自愿**，登记证书是诉讼时的初步证明（了解）

### 知识产权的特征辨析（语义陷阱 · 2026-09-14 用户主动追问）

| 特征 | 描述的是谁 | 含义 |
|---|---|---|
| **无形性** | 知识技术**本身** | 不占据空间，可多人同时使用（非竞争性） |
| **独占性/专有性** | **法律制度赋予**的权利 | 权利人独占，未经许可他人不得使用 |
| **地域性** | 权利的**空间范围** | 仅在申请/登记国有效，跨国要单独申请 |
| **时间性** | 权利的**时间范围** | 保护期届满进入公共领域 |

**关键陷阱（上午题常考）**：题问「知识/技术 具有（ ）」时，答 **无形性**；题问「**专利/著作权** 具有（ ）」时，答 **独占性**。同一现象（可多人用），描述对象不同时答案不同。

**典型题干**：「由于知识技术可以同时被多个人使用，所以知识专利具有（ ）」
- 前半段描述的是知识**本身**的无形性
- 后半段问的是专利**制度**赋予的特征
- 正解：**独占性**（目的论因果：正因为无形可复制，所以需要独占权保护创新激励）

**口诀**：
- "知识/技术 可多人用" → **无形性**（描述对象）
- "专利/著作权 制度赋予" → **独占性**（法律工具）

### 归属（场景题高频）

| 场景 | 著作权归谁 |
|------|------------|
| **职务开发**（员工本职工作、单位主持、单位担责） | 一般归 **单位** |
| **委托开发** | **合同约定**；无约定 → 归 **受托方** |
| **合作开发** | **共同享有**（可合同约定份额） |
| 个人独立开发 | 开发者本人 |

**易混**：委托开发 **没写合同** → 考纲常选 **受托方**，不是委托方。

### 保护期（记大意，不必抠每条款）

| 主体 | 保护期 | 起算点 |
|------|--------|--------|
| **自然人** | 终生 + 死亡后 **50 年** | 从 **死亡** 起算 |
| **法人 / 其他组织** | **50 年** | 从 **首次发表** 起算（截止于首次发表后第 50 年 12 月 31 日；开发完成 50 年内未发表则不再保护） |

**做题先看主体**（2026-10-17 错题钉死）：

- 题干出现「某公司」「某单位」「法人」→ 走 **50 年 + 首次发表**，**不要**选“终生 + 死亡后 50 年”（那是自然人的规则）。
- 题干出现「程序员张某」「作者个人」→ 走 **终生 + 死后 50 年**。

**别和“永久保护三项”混**：署名权、修改权、保护作品完整权**没有期限**，与上面的 50 年保护期是两回事。题干问“保护期是多久”答 50 年；问“哪些权利保护期不受限制”答那三项。

## 三、专利、商标、商业秘密（P1 · 辨型）

| 类型 | 特点 | 与著作权对比 |
|------|------|--------------|
| **著作权** | 自动产生，保护表达 | 软件默认走这条 |
| **发明专利** | 须 **申请**，保护技术方案 | 保护「怎么做」，不是源代码文本 |
| **商标** | 区分商品/服务来源 | 软件产品名、Logo |
| **商业秘密** | 采取保密措施的不公开信息 | 不公开、无固定保护期 |

**考试**：
- 「算法本身」→ 通常用 **著作权** 保护程序表达；**单纯算法** 一般 **不授予专利**（与具体技术方案结合可申请专利，了解即可）
- 「未公开的核心配方/客户列表」→ **商业秘密**

## 四、侵权 vs 合理使用（认场景）

### 常见侵权

- 未经许可 **复制**、发行、传播他人软件
- **破解**、去除版权技术措施
- 抄袭代码/文档表达

### 合理使用（了解，少考）

- 为学习、研究 **少量复制**（非商业）
- 安装软件应遵守 **许可协议**（单机版、企业版、开源许可证各不同）

**开源许可**（了解）：GPL、Apache、MIT 等 — 考「使用开源组件是否要遵守许可证」→ **要**。

## 五、场景 → 答案（速查）

| 题干关键词 | 选什么 |
|------------|--------|
| 推荐性国家标准 | **GB/T** |
| 强制性国家标准 | **GB** |
| 保护源代码和文档 | **著作权** |
| 保护思想、算法本身 | **不**由著作权保护思想 |
| 员工在单位开发本职软件 | 著作权归 **单位** |
| 委托开发且合同未约定 | 归 **受托方** |
| 合作开发 | **共同**享有 |
| 软件文档国标 | **GB/T 8567** |
| 必须申请才取得的权利 | **专利**（著作权自动） |
