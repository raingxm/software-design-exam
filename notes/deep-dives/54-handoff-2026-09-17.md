# 2026-09-17 错题复盘：DNS、DFD、路由器与软件质量

## 本次完成

### DNS 本地解析与分层查询

- 订正“输入网址后本地主机首先在哪里查询对应 IP”：按软考简化口径，先检查本机 `hosts` 文件，而不是本地 DNS 缓存。
- 已区分 `hosts` 与 DNS 缓存：前者是人工维护的静态域名映射，后者是受 TTL 控制的临时查询结果。
- 解释了 DNS 分层查询：本地递归解析器依次获得根服务器对顶级域服务器的转介、顶级域服务器对权威服务器的转介，最终由权威 DNS 返回目标记录。
- 用户已理解“根服务器通常不给最终网站 IP，而是告诉解析器下一步问谁”；尚未做变式验证。

### 数据流图中的数据流与数据存储

- 医院挂号 DFD 题中，用户误选“患者信息”，正确答案为“挂号记录”。
- 已明确：挂号请求、验证过程中传递的患者信息、输出的挂号单都可以是数据流；题干明确“存储到挂号记录”，因此“挂号记录”在当前语境中是数据存储。
- 形成判断规则：提交、发送、读取、返回、输出通常表示数据在移动；保存、存储、登记、归档通常表示数据停留在存储中。同一名称的类型仍取决于其在图中的角色。
- 用户确认该陷阱已理解；尚未做陌生变式。

### 路由器核心功能与扩展能力

- 按题库答案，“路由应有的主要技术有 VPN、QoS、NAT”是错误项。
- 已区分路由器核心职责与扩展功能：核心是建立/维护路由表、按目的 IP 选择下一跳并转发分组；VPN、QoS、NAT 是现代路由器可以支持的扩展能力，并非每台路由器完成基本路由所必需。
- 指出了题目措辞问题：A 的“路由器信息传输”应理解为路由信息通过静态配置或动态协议获得；B 的“实现 IP、TCP、UDP、ICMP 等网络互连”也不严谨，应理解为路由器转发承载这些上层数据的 IP 分组，而不是工作在 TCP/UDP 层。

### ISO/IEC 9126 软件质量模型

- 订正“安全性属于哪项质量特性”：用户选可靠性，正确答案为功能性。
- 已记忆六大质量特性“功、靠、用、效、维、移”：功能性、可靠性、易用性、效率、可维护性、可移植性。
- 已区分：ISO/IEC 9126 将安全性作为功能性的子特性；可靠性关注成熟性、容错性和易恢复性。
- 补充版本陷阱：后续 ISO/IEC 25010 将安全性提升为独立一级特性，本题明确问 9126，必须选功能性。
