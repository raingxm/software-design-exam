# 递归式复杂度 · 考场快速判断

> 2026-09-07 错题回炉：`T(n)=2T(n/2)+n log n`
> 目标：不背完整主定理，也能用“相邻两层总工作量”判断常见递归式的渐近紧致界。

---

## 一、先把递归式读成人话

```text
T(n) = aT(n/b) + 额外工作
```

- 当前规模为 `n`。
- 一次拆成 `a` 个子任务。
- 每个子任务规模变成 `n/b`。
- 加号后面是当前任务在递归之外还要做的工作。

例：`T(8)=2T(4)+24` 表示“规模 8 的任务拆成 2 个规模 4 的任务，另外做 24 份工作”。

---

## 二、相邻两层比较法

若额外工作的主体是 `n^q`：

```text
每拆一层：任务数量乘 a
每个任务：规模除以 b，n^q 工作量除以 b^q
本层总量：比较 a 与 b^q
```

| 比较结果 | 层间变化 | 谁主导 | 常见结论 |
|---|---|---|---|
| `a < b^q` | 下一层按固定比例变小 | 顶层 | 保留加号后的工作量 |
| `a = b^q` | `n^q` 部分正好抵消 | 各层 | 若带 `log^k n`，结果多一个 `log n` |
| `a > b^q` | 下一层按固定比例变大 | 底层 | 找 `a=b^p`，底层有 `n^p` 个任务 |

本表用于软考常见的 `n^q log^k n` 标准题型。

### 幂次换算

```text
规模除以 2：n 除以 2，n^2 除以 4，n^3 除以 8
规模除以 3：n 除以 3，n^2 除以 9，n^3 除以 27
```

## 三、本次原错题

```text
T(n) = 2T(n/2) + n log n
```

1. 任务数量乘 2，`n` 工作量除以 2，主体正好抵消。
2. 每次规模减半，共约 `log n` 层。
3. 各层对数部分依次为 `log n, log n-1, ..., 1`。
4. 原有一个 `log n`，抵消后跨层累加再增加一个 `log n`。

结论：`Theta(n log^2 n)`。

---

## 四、本次掌握证据与易错点

### 已能独立完成

- 能把 `T(8)=2T(4)+24` 准确翻译为任务拆分和额外工作。
- 能判断 `2T(n/2)+n` 为 `Theta(n log n)`。
- 能判断抵消型 `4T(n/2)+n^2 log n` 为 `Theta(n^2 log^2 n)`。
- 能判断顶层主导型 `2T(n/2)+n^2 log n` 为 `Theta(n^2 log n)`。
- 能判断底层主导型 `27T(n/3)+n^2 log n` 为 `Theta(n^3)`。

### 需要继续防错

1. 规模除以 2 时，`n^2` 工作量是除以 4，不是除以 2；`n^3` 是除以 8。
2. `9T(n/3)` 的底层是 `n^2`，因为 `9=3^2`；只有 `27T(n/3)` 才对应 `n^3`。
3. “log 次数加一”只用于主体幂次正好抵消的标准题，不能见到递归就机械加一。
4. 题目问渐近紧致界时写 `Theta`；`O` 只表示上界。

## 五、晚上续学入口

先闭卷完成下面三题，每题写“底层基准、谁获胜、最终答案”：

```text
1. T(n) = 16T(n/2) + n^3 log^2 n
2. T(n) = 9T(n/3) + n^2 log^3 n
3. T(n) = 2T(n/2) + n^3
```

<details>
<summary>完成后核对答案</summary>

1. `Theta(n^4)`：`16=2^4`，底层 `n^4` 胜过 `n^3 log^2 n`。
2. `Theta(n^2 log^4 n)`：`9=3^2`，主体抵消，log 次数加一。
3. `Theta(n^3)`：加号中的 `n^3` 比底层基准 `n` 更大，顶层主导。

</details>
