## 总口令

```text
n 位补码：-2^(n-1) ～ 2^(n-1)-1；0 唯一，所以多一个最负的数
正数补码=原码；负数=原码取反再 +1
二进制 → 十六进制：4 位一组；10=A … 15=F；H 只是进制标记

流水线=不同硬件段叠着干不同指令，不是一条指令拆开随便并行
同步流水线靠统一时钟交班 → Δt=最长一段（快的空等）
T = (k + n - 1) × Δt
```

## 刀1 · 补码 ✅

### 范围

n 位一共 \(2^n\) 个码。原码/反码有两个零，范围对称：\(-(2^{n-1}-1)\)～\(2^{n-1}-1\)。  
补码 0 只留一个，腾出的码给 \(1000\ldots0\) = \(-2^{n-1}\)。

| 位数 | 补码范围 | 那个多出来的码 |
|------|----------|----------------|
| 8 | **-128～127** | `10000000` = -128 |
| 16 | **-32768～32767** | `1` + 15 个 `0` = -32768 |

摸底第 1 题陷阱：把原码的 -127～127 套到补码上。

### 书写

- **+13** 八位：`0000 1101` → 高 4 位 0、低 4 位 13=D → **0DH**
- **-13** 八位：`0000 1101` 取反 `1111 0010`，+1 → `1111 0011` → **F3H**

`H` 不是数据。摸底第 22 题问 +13，答案 0DH；F3H 是 -13 的干扰项。

### 已过关

- 16 位范围 -32768～32767，理由：0 唯一，`1000…0` 是 -32768
- -13 → F3H（原码→反码→+1，再 4 位一组）

## 刀2 · 流水线 ✅

### 它是什么

一条指令四步用的是**四套不同电路**（取指单元、译码器、ALU、写回）。  
同一时刻：ALU 算第 1 条、译码器看第 2 条、取指拿第 3 条。  
并行的是**不同段、不同指令**，不是四条指令各干各的、互不等待。

### 为什么有固定节拍

软考默认**同步流水线**：段与段之间夹寄存器，同一个时钟边沿一起交班。  
节拍结束时下一段会把你的输出当成品拿走，所以**每一段必须在这一拍内做完**。  
执行要 4ns、取指只要 2ns：取指先做完也得空等，因为交接绑在一起。节拍 \(\Delta t\) = 最慢那段。

异步（干完就传）存在，但公式 \(T=(k+n-1)\times\Delta t\) 不适用，考试不考。

### 计算

摸底第 9、11 题陷阱：把各段时间**加起来**当 Δt。那是「一条独自做完全程」，不是节拍。

例：取指 2、译码 2、执行 4、写回 2（单位 ns），k=4，n=100。

- \(\Delta t = 4\)（不是 10）
- \(T = (4+100-1)\times 4 = 412\) ns

### 已过关

- 「取指 2ns 仍每 4ns 才拿下一条」——对，等统一交班，不是取指慢
- Δt=4ns，T=412ns
