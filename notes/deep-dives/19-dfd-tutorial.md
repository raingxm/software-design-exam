## 一、口令（够用了）

```text
说明圈名字 → 图上对人、对箭、对加工 → 没有就补
父子平衡   → 只对「进出这道加工」的进出口对账；肚子里的箭不算
加工       → 改变数据含义的步骤；必须有进有出
```

### 读题防晕（比做题更重要）

下午真题是**印刷图**：方框=实体，圆/圆角=加工，双横线=库，箭头旁小字=流名。  
形状已经区分身份——**不会靠加粗告诉你「这是流还是加工」**。

自编 ASCII 题若「图上文字注解 + 示意残缺 + 随意加粗」，会故意让人晕。约定：

| 看见什么 | 它是什么 | 怎么认 |
|----------|----------|--------|
| `[名字]` | 外部实体 | 方括号 |
| `(P× 动词…)` | 加工 | 圆括号 + 编号 |
| `[=D× …=]` | 数据存储 | 双线夹名字 |
| `A --> B` 旁的词 / `--流名-->` | 数据流 | 只贴在箭上 |

```text
做题只信两样：① 说明段落  ② 图上的形状
加粗、问号注释、题干里的「多画：…」都是辅导噪音，真题没有
```

**一次只干一件事**（不知所措时按这个顺序，不要同时找所有缺口）：

```text
第 1 遍说明：只圈「人/外系统」→ 对图找方框
第 2 遍说明：只圈「动词步骤」→ 对图找圆框（加工）
第 3 遍说明：只圈「单据/信息名」→ 对图找箭上的字
第 4 遍（若有子图）：只抄父加工进出口清单 → 和子图边界对勾
```

**四要素（人话）**

| 叫什么 | 是什么 | 图上大致样子 |
|--------|--------|--------------|
| 外部实体 | 系统外的人/组织/别的系统 | 方框 |
| 加工 | 系统里干活的一步（数据含义会变） | 圆角框 / 圆 |
| 数据存储 | 数据停放处（表、文件） | 两条横线 |
| 数据流 | 正在移动的、**有名字**的数据 | 带名箭头 |

## 二、加工专项（2026-08-05 补强）

### 人话

```text
进来数据 → 处理后含义变了 → 送出去  = 加工
只存放不运算                         = 库
系统外的人/系统                       = 实体
```

### 硬性规矩

```text
① 每个加工必须有进有出（禁黑洞 / 禁奇迹）
② 实体↔实体、库↔库 不能直接连
③ 实体↔库 一般要经加工
```

### 缺加工怎么找

说明里的「办事步骤 / 动词短语」→ 图上有没有对应圆框。  
有步骤无圆框 → **补加工**（常连带补进出流）。

与缺流区分：框都在少箭 = 缺流；少了一个干活框 = 缺加工。

### 分层

```text
0 层：P1、P2、P3 …（看不到 P2.1）
子图：把 Pi 拆开 → Pi.1、Pi.2 …（做父子平衡才打开）
```

## 五、下午题侦探顺序

1. 说明圈：谁 / 什么单 / **哪一步（加工）** / 存哪  
2. 对残图：实体 → 加工 → 流（每框有进有出）  
3. 有子图：只对父加工**进出口**清单对账（多了 / 少了）  
4. 信说明，图是残的  

### 父子平衡口令（再背）

```text
列出父图进出该加工的所有流名
子图边界必须能一一对上
子图内部箭可以有；多出来的对库/对外流 = 多了
父有子无 = 少了
```
