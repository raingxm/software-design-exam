双向循环链表插入

目标：看懂“语句顺序改变指针含义”，避开覆盖旧指针的陷阱。

1. 只画三个结点

插入前：p ⇄ q　（q = p->next）
插入后：p ⇄ s ⇄ q

插入后必须同时满足四条边：p.next=s、s.prior=p、s.next=q、q.prior=s。双向链表相邻结点的前后链接必须互相对应；参见 OpenDSA。

2. 安全写法

q = p->next;          // 先保存旧后继
s->next = q;
s->prior = p;
q->prior = s;
p->next = s;          // 最后改入口

去掉临时变量 q，就得到题目的 D：在执行最后一句前，p->next 仍是旧后继。

3. B 为什么错

p->next->prior = s;  // 旧 q.prior = s
p->next = s;         // 从此 p.next 已经是 s
s->prior = p;
s->next = p->next;   // 实际是 s.next = s，自环

考试口诀：旧后继先读取，入口指针后覆盖。不要只核对四条赋值“有没有”，要逐句核对右侧表达式“此刻指向谁”。

4. 一分钟检验

若把 D 的最后两句交换，会得到什么错误？先在纸上逐句追踪，再展开答案。

查看答案

交换后先执行 p->next=s，随后 p->next->prior=s 访问的就是 s.prior，把它从 p 覆盖成 s；产生错误的自指前驱。

建议继续向老师追问：删除结点时为什么也要先保存邻居？
