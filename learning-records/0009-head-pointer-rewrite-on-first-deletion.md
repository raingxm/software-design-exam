# 已掌握不带头结点删除首元时的头指针改写

用户理解不带头结点的单链表删除首元结点必须先保存旧首元、让调用者的头指针指向下一结点，再释放旧首元；直接 free 会使头指针悬空并丢失整条链。C 函数需通过 `Node **head` 改写调用者变量，并检查 `head != NULL && *head != NULL`。

## Evidence

用户先答"直接 free"，经逐句手推 q、L 指向变化与 n=2 小实例后确认理解，并主动追问头指针与链表本身的区别直至厘清"改头指针"与"改前驱 next 域"的差异。2026-09-09 变式验收中，能判断 `A -> B -> C` 删除首元后调用者头指针应指向 B；首次写二级指针代码暴露 `*head->next` 的优先级错误，订正后闭卷完整写出 `*head = (*head)->next` 与双重空指针检查，本项结清。
