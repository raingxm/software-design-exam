## 试题四 · n 皇后递归回溯

- 正确四空：`queen[i] == queen[j]`、`1`、`Place(j)`、`Nqueen(j + 1)`。

## 试题五 · Java 策略模式

- 五空全部正确：`void stop()`、`BrakeBehavior`、`wheel.stop()`、`this.wheel = behavior`、`brake()`。
- `this` 表示当前对象。字段与参数重名时必须用 `this.field` 消歧；不重名时通常可省略。
- 本题 `wheel.stop()` 等价于 `this.wheel.stop()`，`wheel = behavior` 也等价于 `this.wheel = behavior`，`brake()` 等价于 `this.brake()`。
