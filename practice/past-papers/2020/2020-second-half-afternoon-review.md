## 试题四 · 希尔排序

- `(1)` 应为 `k = k / 2`，原答正确。
- `(2)` 应为 `k > 0`，原答 `k > 1` 会在存入增量 `1` 后直接退出，漏掉用于终止外层循环的哨兵 `0`。
- `(3)` 应为 `(dk = delta[i]) > 0`。原答 `dk = delta[i] && i < delta` 同时存在三处问题：赋值优先级使 `dk` 得到的是布尔值；`delta` 是指针，不能作为有效长度比较；而且程序真正依靠 `delta` 中的 `0` 退出。
- `(4)` 应为 `data[j+dk] = t`；插入循环结束后 `j` 已退到目标位置之前，所以回填在 `j+dk`。
- 时间复杂度小于 `O(n^2)`、算法不稳定均正确。
- 首趟增量 `dk=3` 时，子序列下标 `0,3,6` 的 `15,8,4` 应排为 `4,8,15`；正确整列为 `4, 9, -1, 8, 20, 7, 15`。原答把下标 0、3 的值颠倒。
- **估分**：严格按空计约 `6/15`。第 3 空虽意识到要读取 `delta[i]`，但表达式不能正确运行，因此不另计完整分。

这题最终形成的执行模型是：

1. 生产端把增量依次写成 `3 -> 1 -> 0`；`malloc(n/2)` 只是数组容量，不是已写入项数。
2. 消费端每轮用 `(dk = delta[i]) > 0` 同时完成“取当前增量”和“检查哨兵”。如果只保存 `[3, 1]`，就必须另设 `gapCount=2`，原程序并没有这个计数。
3. `dk=3` 时分成下标组 `(0,3,6)`、`(1,4)`、`(2,5)`，分别做完整的插入排序；再以 `dk=1` 对全表做最后一轮插入排序。
4. 现场校验不必先彻底掌握全部理论：直接用问题 3 给出的数组追踪“生产了哪些增量、每组有哪些下标、回填位置是否为 `j+dk`”，题目自带样例就是边界调试器。
