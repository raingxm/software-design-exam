## 试题三 · 数字图书馆 UML

参考口径允许 `C3/C4/C5` 互换，本次排列与参考答案一致。

### 问题 2 · 属性

- `C6 Publication`：题目、作者、出版年份。
- `C7 ConfPaper`：会议名称、召开时间、召开地点。
- `C8 JournalArticle`：期刊名称、出版月份、期号、主办单位。
- `C9 TechReport`：学校分配的唯一 `ID`。

### 问题 3 · 设计模式

- 模式：观察者模式。
- 功能：用户为出版物注册引用通知；出现新的引用后，系统向用户发送电子邮件。

### 本题验证的方法

1. **连线分簇**：人员层次与出版物层次分开处理。
2. **找父类**：`User` 是三类校内用户的父类；`Person` 是 `User` 与图中 `Author` 的共同抽象；`Publication` 是三类出版物的父类。
3. **回题干取原词**：优先使用题干给出的英文类名；`Person` 由共同父类位置补出。
4. **检查类号**：`Proceedings` 关联锁定 `ConfPaper`，`Edition` 关联锁定 `JournalArticle`，剩余位置为 `TechReport`。

结论：此前“类名正确但整体错位”的问题在本题未复现，陌生类图节点映射验收通过。

## 试题四 · 哈密尔顿回路

### 作答

```c
(1) visited[0] = 1;
(2) visited[x[k]] == 0
(3) c[x[k]][x[0]] == 1
(4) visited[x[k]] = 1;
(5) k = k - 1;
```

- 设计策略：回溯法。
- 图遍历方式：深度优先。

布尔方向、末顶点到起点的闭环条件、访问标记与层号回退均命中参考答案。

### 题面固定代码缺陷

原题回退分支的固定顺序为：

```c
x[k] = 0;
visited[x[k]] = 0;
k = k - 1;
```

执行 `x[k] = 0` 后，第二句实际清除的是 `visited[0]`，而不是退出路径的上一层顶点。按可执行逻辑，更合理的顺序是：

```c
x[k] = 0;
k = k - 1;
visited[x[k]] = 0;
```

因此本题须区分：考试填空答案全部正确；完整程序本身仍有固定语句顺序缺陷，该缺陷不记为作答错误。
