## 试题四 · 算法

- 正确填空：`r <= N`、`j = i + r - 1`、`temp < m[i][j]`、`S[i][j] + 1, j`。
- 原答第三空逻辑等价正确；动态规划、`O(n^3)`、`O(n^2)` 全对。
- 题面存在明确转录错误：内层条件把 `i` 印成 `k`，初始化注释把 `k=i` 印成 `k=j`，枚举起点把 `i+1` 印成 `j+1`。
- 已独立理解第一空：规模为 `r` 的连续子问题数量是 `N-r+1`；`r=N` 时仍有 1 个，`r=N+1` 时才为 0，因此上界含等号。区间口令为“终点 = 起点 + 长度 - 1；右半段从分割点 + 1 开始”。
- **状态**：讲解后确认理解，待一题无错印的区间 DP 变式验证边界。
