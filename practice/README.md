- **口令**：① 考题自定义 `Clone()` → 复制一律 `new`，`super()` 只属于构造器首行 ② 凡接住 `Object` 返回值先强转——强转只出现在「接住返回值」处 ③ 引用类型字段必须 `Clone`，基本类型直接抄 ④ **私有构造器 = 克隆站：进的是原件，存的是副本**

### 2026-09-01 · 数据结构 · 完全二叉树叶子数错题

- **来源**：2026.08.31《软件设计师》每日一练截图第 1 题
- **限时**：未计时（概念辨析）
- **题目**：一个有 124 个叶子节点的完全二叉树，最多有多少个结点？
- **题库给答**：249
- **订正**：按标准完全二叉树定义，正确应为 **248**。完全二叉树若有 n 个结点，则叶子数为 `ceil(n / 2)`；`ceil(247 / 2) = 124`，`ceil(248 / 2) = 124`，所以最多为 248。
- **错因**：对“完全二叉树”概念未建立；容易把“完全二叉树”和一般二叉树性质混用，或被题库误标答案带偏。
- **回看**：[数据结构回顾 · 树与二叉树](../notes/03-data-structures/01-data-structures-review.md)
- **口令**：完全二叉树像数组从 1 号位开始从左到右填；叶子在后半段，叶子数看 `ceil(n/2)`。
