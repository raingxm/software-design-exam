# 中断机制 · 快练 4 题 · 答案与解析

> 对应题目文件：[09-interrupt-mechanism-drill.md](./09-interrupt-mechanism-drill.md)

---

## 第 1 题：答案 **B**

**解析：**
- 中断向量表（IVT）中每个条目就是一个**中断向量**，也就是对应中断服务程序（ISR）的入口地址。
- A 是 I/O 端口地址；C 由 CPU 自动保存；D 是 DMA 或缓冲区概念。

---

## 第 2 题：答案 **D**

**解析：**
- A、B、C 都正确。
- D 错误：**NMI（不可屏蔽中断）不受 IF 标志位控制**。IF 只能控制可屏蔽中断。NMI 用于处理紧急情况，如掉电、内存校验错误等。

---

## 第 3 题：答案 **D**

**解析：**
- A 错误：一片 8259A 有 8 个中断输入引脚（IR0~IR7），最多管理 **8 个**中断源；级联后最多 64 个。
- B 错误：ISR 记录的是**正在被服务的中断**；记录请求的是 **IRR**（Interrupt Request Register）。
- C 错误：NMI 不能被 IF 屏蔽。
- D 正确：这正是 8259A 的核心作用——多中断源管理、优先级裁决、向 CPU 提供中断类型号。

---

## 第 4 题：答案 **C. 00080H**

**解析：**
- 实模式下每个中断向量占 4 个字节。
- 起始地址 = 中断类型号 × 4 = 20H × 4 = 80H。
- 因此起始地址为 **00080H**。

---

## 口头自测答案

1. 一片 8259A 有 **8 个**中断请求输入引脚（IR0~IR7）；级联后最多管理 **64 个**中断源（1 主片 + 8 从片）。
2. 最关键区别：**可屏蔽中断受 IF 标志位控制，NMI 不受 IF 控制**。
3. CPU 第二次收到 INTA 时，**8259A 把该中断对应的中断类型号送上数据总线**，CPU 据此去查中断向量表。
