## 类图

| 题 | 答 |
|----|-----|
| **C1** | **符合**（均为泛化） |
| **C2** | 应为 **组合**；**实心菱形**在 **课程**端；残图错在画成了**空心菱（聚合）** |
| **C3** | **关联** |
| **C4** | `学员 1 ———— * 报名记录 * ———— 1 课程` |
| **C5** | **依赖** |

C4 示意图：

```text
[学员] 1 ---------- * [报名记录] * ---------- 1 [课程]
```

## 用例

| 题 | 答 |
|----|-----|
| **U1** | **include**；箭头：报名课程 → 验证登录 |
| **U2** | **extend**；箭头：在线支付 → 报名课程 |
| **U3** | **在线支付** |
| **U4** | **否**（说明未给出讲师相关用例，不必强行加） |

## 复盘

```text
组合=实心菱+整体端；聚合=空心菱
中间类报名记录：1——*——1
必做登录=include；可选支付=extend
网关连真正交互的用例
```
